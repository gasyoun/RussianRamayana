# 17. Деление сводного указателя на отдельные части

_Created: 08-07-2026 · Last updated: 08-07-2026_

---

Делим большой сводный указатель на наши четыре.

Заготовлены названия указателей; сноска одна на все указатели. Идём по алфавиту сверху:

1. **Именной указатель.** Доходим до буквы `B` — здесь начинается уже другой указатель. Полезный скрипт `SplitStory` (папка «Useful Support Tools»): выделяем материал в текстовых фреймах — вот один материал, вот другой; можно выровнять по низу. Затем поиском с заменой убираем префикс: в поле «найти» — начало абзаца с буквой указателя, в поле «заменить» пусто; «найти» → «заменить» по всему материалу.
2. **Географические названия.** Так же доходим до буквы `C`. Если вид сменился с двухколоночного на одноколоночный — поправляем объектным стилем «страница указателя». Снова тот же `SplitStory`, затем поиск/замена: меняем букву-префикс (`b` → `c` и т. д.) и удаляем её в материале.
3. **Предметы и термины.** Символьный стиль убрать; при делении теряется оформление — восстанавливаем. Тот же скрипт, поиск/замена по своей букве.
4. **Флора и фауна** — аналогично, по своей букве.

Готово — четыре отдельных указателя, соответствующих листам `.xlsx`. Дальше с ними можно работать и переходить к собственно вёрстке; правя `IndexList`, вносить адресные изменения.

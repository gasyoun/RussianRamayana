Собираем четыре таблицы в одну сводную.

**Почему так.** Нам нужны четыре указателя, но в объектной модели InDesign указатель — это массив, в котором может быть только **один** элемент-указатель. Поэтому мы строим один сводный указатель, а затем режем его на четыре. Чтобы потом разделить, перед объединением ставим перед каждым термином латинскую букву и дефис: в первом указателе `A-`, во втором `B-`, затем `C-` и `D-`. После сборки строки отсортируются по `A, B, C, D`, а внутри каждой буквы — по словам. Формально для InDesign это один указатель; мы его потом разберём на нужные нам четыре.

**Проставляем буквы-маркеры** скриптом `AddMarker.jsx`:
1. Открываем первый указатель, удаляем оставшуюся служебную строку.
2. Ставим курсор в первую колонку, запускаем `AddMarker.jsx` — добавляется буква `a`.
   > Совет: перед каждым таким шагом полезно спрятать/скопировать резервную копию — места занимает мало, а время экономит.
3. Для второго указателя так же получаем `b`, для третьего — `c`, для четвёртого — `d`.

**Объединяем** скриптом `MergeTwoIndexListTables.jsx` (имя активного файла-приёмника должно начинаться с `@`):
1. Первый файл, к которому всё прицепляется, переименовываем так, чтобы вместо буквы стояло коммерческое «эт» — `@`.
2. Открываем этот файл и второй файл (с буквой `b`), делаем активным приёмник (`@…`), запускаем скрипт — вторая таблица добавляется в конец главной.
3. Закрываем второй, открываем третий (`c`), снова делаем активным приёмник, запускаем — добавлено. То же с четвёртым (`d`, флора и фауна).

В итоге получаем сводную таблицу `IndexList[@]-001` — большую, со всеми терминами из `.xlsx`. С ней и будем собирать весь указатель целиком.

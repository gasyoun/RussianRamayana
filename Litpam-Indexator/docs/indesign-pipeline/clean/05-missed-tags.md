Доразметка пропусков (файл ошибок совсем небольшой).

1. Создаём новый файл (без разворота), помещаем в него файл с необработанными тегами, сохраняем.
2. Открыты два файла. Идём по тегам скриптом `#ApplyCharacterStyle.2024.jsx`, для каждого ставим курсор и ищем нужный случай в вёрстке, затем применяем стиль и переходим к следующему.

Так по очереди отмечаем оставшиеся термины (имена, отсылки к легендам и т. п.). Пройдя все, закрываем — второй материал первого тома обработан.

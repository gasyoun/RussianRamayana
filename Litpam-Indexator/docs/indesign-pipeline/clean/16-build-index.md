# 16. Подготовка указателя

_Created: 08-07-2026 · Last updated: 08-07-2026_

- 🔧 Стадия: **[4] Оформление указателя** · Скрипт: `ProcNumberLines[3-4,6-8].jsx`

---

Пришло время собрать указатель (пока один сводный, потом поделим).

**Сборка.** Панель «Указатель» → «Построить указатель». Через ~4 минуты готово. В начале идет буква `A`, дальше `B` и т. д. (буквы-маркеры разных указателей).

**Приведение в порядок** — два момента:
1. Идущие подряд номера страниц надо схлопнуть в диапазон через дефис (например, `85, 26, 27` → диапазоны через минус).
2. Все ссылки-номера из **Примечаний** сделать полужирными.

Оба делаются скриптом из стадии `[4]`, папка «Оформление номеров страниц в указателе» — `ProcNumberLines[3-4,6-8].jsx`:
1. Указываем область обработки. Для терминов используется символьный стиль «термин».
2. Задаем диапазон страниц примечаний/дополнительной информации, который надо делать полужирным (в примере `246–380`), помечаем его как диапазон, выбираем стиль «страница в комментарии», ставим минус между числами.
3. «Обработать».

Получаем указанный диапазон полужирным и схлопнутые номера. В следующем видео делим большой сводный указатель на четыре части.

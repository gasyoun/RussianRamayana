Здесь собраны файлы для подготовки указателя именно к «Рамаяне». Есть один отдельный момент, который здесь учтён: помимо обычных папок стадий `[1]`–`[4]` (как в других проектах) добавлена ещё папка `[0. Работа с тегированной разметкой]` — то, что делает разметчик (Анатолий), здесь тоже учтено. Покажу всё по шагам.

Сначала — исходное состояние. Вот сам файл вёрстки, с которым будем работать. Прежде чем начинать заново, покажу, как очистить уже наработанный указатель, чтобы всё было чисто:

1. Идём в стадию индексирования `[3]` и запускаем скрипт, выбрав «удалить все имеющиеся записи»,  — данные будут собраны заново.
2. Убираем результат и сворачиваем.
3. Нужна ещё группа символьных стилей «Index styles»: в ней лежат все стили, которые создаёт разметка. Выделяем в этой группе все стили и удаляем их **без сохранения форматирования**, чтобы снялся цвет.
4. Остаётся только текст, окрашенный служебным цветом. Выделяем его и задаём чёрный цвет.

Теперь исходник чистый — всю разметку заново построит наш конвейер. Приступаем.

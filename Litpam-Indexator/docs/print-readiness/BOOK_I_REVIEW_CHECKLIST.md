# BOOK_I_REVIEW_CHECKLIST — детерминированная выборка ручной проверки книги I

_Created: 14-08-2026 · Last updated: 14-08-2026_

Ручная (человеческая или агентно-визуальная) половина QA пилота книги I
(рулинги 15, 20
[PLAN](https://github.com/gasyoun/RussianRamayana/blob/main/Litpam-Indexator/docs/PLAN_LITPAM_INDEXATOR_PRINT_READINESS_2026.md)).
Машинную половину (полный проход каждой ссылки и каждой статьи) делает `coverage`
из [H2589 (Sonnet 5) — deterministic tooling и print-readiness пилот книги I](https://github.com/gasyoun/Uprava/blob/main/handoffs/H2589-Sonnet_RussianRamayana_litpam-book1-print-readiness-pilot_12.08.26.md);
этот чек-лист НЕ выборка вместо машинной полноты, а выборка для того, что машина
не оценивает (визуальное качество, редакционная точность глосс).

Правила детерминизма: выборка вычисляется из регенерированного указателя
алгоритмически (ниже), без генератора случайных чисел; повторный расчёт на том же
указателе даёт тот же список. Параметры — `review_sample` в
[config/print-readiness.json](https://github.com/gasyoun/RussianRamayana/blob/main/Litpam-Indexator/config/print-readiness.json).
Каждый пункт получает строку в defect ledger — включая вердикт «чисто»
(правило записи №1
[DEFECT_POLICY.md](https://github.com/gasyoun/RussianRamayana/blob/main/Litpam-Indexator/docs/print-readiness/DEFECT_POLICY.md)).

| A5 | Все пары статей, различающиеся только регистром/вариантом написания (из отчёта валидатора словника); если пар >5 — первые 5 по листу | случайные дубли против законных вариантов «, или» |

## B. Пополосные проверки (весь диапазон указателей книги I)

| # | Полосы | Что проверяется |
|---|---|---|
| B1 | Полоса-открытие каждого указателя (в печати 2025: 415, 428, 431, 437 — на регенерате пересчитать) | новая полоса; заголовок первым элементом; фурнитура по default D6 spec; для первой полосы блока — подстрочное примечание §7.4 |
| B2 | Последняя полоса каждого указателя | короткая полоса допустима; нет orphan-строк; следующий указатель не начинается в подбор |
| B3 | Каждая 5-я полоса указателей, начиная с первой (415, 420, 425, 430, 435 + последняя) | колонтитулы verso/recto (§6), колонцифры, баланс колонок, сетка |
| B4 | Все полосы, где автопроверка H2589 нашла хоть один FAIL | визуальное подтверждение/опровержение каждого машинного FAIL |
| B5 | Стык «приложения → указатели» (в 2025: 414→415) | нет призрачных полос (класс D8 spec, наблюдение тома II) |

## C. Порядок прохода и фиксация

1. Проход строго по порядку A1→A10, B1→B5, указатель за указателем (1→4).
2. Вердикт каждой строки: `PASS` / `FAIL <класс> <правило spec>` / `WAITING` —
   в defect ledger (формат — [DEFECT_POLICY.md](https://github.com/gasyoun/RussianRamayana/blob/main/Litpam-Indexator/docs/print-readiness/DEFECT_POLICY.md) §3).
3. Итог чек-листа — одна строка в evidence packet: счётчики
  `PASS/FAIL-by-class/WAITING` + ссылка на ledger. Статус пилота при всех
  машинных PASS и закрытых blocker/material —
  `AUTOMATED_PASS / HUMAN_REVIEW_WAITING` (шаг 6
  [IMPLEMENTATION](https://github.com/gasyoun/RussianRamayana/blob/main/Litpam-Indexator/docs/IMPLEMENTATION_LITPAM_INDEXATOR_PRINT_READINESS.md)):
  человеческая приёмка не симулируется (рулинг 25).

# RuWritingStyles — Полный пакет

Стилистические портреты русских филологов и лингвистов для нейронок.  
Репозиторий: [github.com/gasyoun/RuWritingStyles](https://github.com/gasyoun/RuWritingStyles)

---

## Файлы этого пакета

### Для чтения

| Файл | Что внутри | Читать первым |
|---|---|---|
| **`THEORY.md`** | Апресян и Падучева как метатеория пайплайна | Если хочется понять *почему* |
| **`rws_onboarding.md`** | Пошаговая инструкция: docx → CLI → отчёт | Если хочется *запустить* |
| **`FAQ.md`** | 40 вопросов: форматы, измерения, ошибки, вклад | Если что-то пошло не так |
| **`style_md_template.md`** | Шаблон _style.md с заполненным примером + галерея | Если пишешь новый стиль |

### Для запуска

| Файл | Что делает |
|---|---|
| **`rws_pipeline.py`** | Главный скрипт: корпус → 4 файла (stylometry, rules, dh_section, .yml) |

```bash
pip install pyyaml python-docx
python3 rws_pipeline.py tg  export.json    handle "Имя Автора"
python3 rws_pipeline.py txt article.txt   handle "Имя Автора"
python3 rws_pipeline.py csv posts.csv     handle "Имя Автора"
```

## Архитектура за 30 секунд

```
КОРПУС (жанрово однородный)
  │
  ▼ rws_pipeline.py
  │
  ├─ 13 ИЗМЕРЕНИЙ
  │   TTR · POS · номинализация · кейнесс · эпист.модальность ·
  │   синтаксис · инципит · отрицание · динамика · код-свитчинг ·
  │   ссылки · ритм · академич.базелайн
  │
  ├─ ТРАНСЛЯЦИЯ  (измерение → правило с source-трассировкой)
  │
  └─ ВЫХОД
      _stylometry.md   числа + бенчмарки
      _rules.md        правила ← ПРОВЕРИТЬ ВРУЧНУЮ
      _dh_section.md   вставить в _style.md
      .yml             паспорт агента

+ вручную:
  ClaudeStyles/<handle>-style.md   полный портрет
  main_intonation                  единственное поле, которое нельзя вычислить
```

**Одна пара (автор, жанр) = один прогон.**  
Зализняк — 8 прогонов, 8 файлов, один паспорт.

## Теоретический стержень

Пайплайн опирается на два теоретических столпа — **не как объекты изучения, а как инструмент интерпретации**:

**Апресян** объясняет, почему кейнесс работает (семантические поля), почему номинализация диагностична (трансформация событие→объект), почему матрица трансляции осмысленна (обратная МТТ).

**Падучева** объясняет, почему hypo/para важен (пропозициональные установки), почему ирония через архаику — отдельная категория (несобственно-прямая речь), почему `main_intonation` — это «точка зрения» в техническом смысле.

Подробно → [`THEORY.md`](THEORY.md)

## Добавить нового автора: минимальный чеклист

```
□ Собрать корпус (≥ 100 единиц одного жанра)
□ Настроить DEFAULT_CONFIG в rws_pipeline.py:
    genre, personal_kw, work_kw, l2_pattern,
    manual_limits, EPISTEMIC['ironic_cite']
□ python3 rws_pipeline.py <mode> <file> <handle> "Автор"
□ Открыть _rules.md → проверить вручную (противоречия, пропуски)
□ Сформулировать main_intonation (одна прескриптивная фраза)
□ Написать ClaudeStyles/<handle>-style.md
□ git add / commit / PR
```

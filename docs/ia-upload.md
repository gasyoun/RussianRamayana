## Команды загрузки (ia CLI)

```sh
pip install internetarchive
ia configure   # однократно, логин archive.org

ia upload ramayana-russian-1986 \
  "Рамаяна 1986. Книга 1. Бала-канда.mp3" \
  "Рамаяна 1986. Книга 2. Айодхья.MP3" \
  "Рамаяна 1986. Книга 3. Лесная.MP3" \
  "Рамаяна 1986. Книга 4. Кишкиндха.mp3" \
  "Рамаяна 1986. Книга 5. Прекрасная.MP3" \
  "Рамаяна 1986. Книга 6. Битва.MP3" \
  "Рамаяна 1986. Книга 7. Последняя.MP3" \
  --metadata="mediatype:audio" \
  --metadata="collection:opensource_audio" \
  --metadata="title:Рамаяна. Аудиокнига на русском языке в переводе В. Потаповой (1986)" \
  --metadata="creator:Вальмики" \
  --metadata="date:1986" \
  --metadata="language:rus" \
  --metadata="subject:Ramayana; Valmiki; Рамаяна; аудиокнига; Потапова" \
  --metadata="rights:Запись публикуется с письменного разрешения Евгения Кривецкого, правообладателя записи."
```

## После загрузки

1. Сверить SHA-256 (IA отдаёт md5/sha1 в `_files.xml`; при необходимости скачать и пересчитать).
2. В [data/audio.json](../data/audio.json) заменить `url` на
   `https://archive.org/download/ramayana-russian-1986/<файл>` для всех 7 книг;
   книги 5–6 перевести в `status: "available"`.
3. В [audio.html](../audio.html) убрать формулу «превышает лимит GitHub»; добавить ссылку на item.
4. Только после проверки плеера — чистка git-истории (`git filter-repo`, см. Фазу 1 роадмапа).

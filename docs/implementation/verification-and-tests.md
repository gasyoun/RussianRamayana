# Verification And Tests

Этот файл — индекс проверок. Подробности разбиты на короткие документы.

## Документы

- `verification-automated.md` — команды, которые надо запустить.
- `verification-manual.md` — ручная проверка в браузере и по содержанию.

## Общий Pass/Fail

Фаза 1 считается принятой только если:

- все автоматические проверки проходят;
- локальная браузерная проверка проходит;
- контентная проверка проходит;
- изменение можно откатить без потери текущего аудио и карты.

## Что Проверяем

- Созданы все ожидаемые файлы.
- JSON валиден.
- На главной есть блок поддержки.
- `support.html` открывается.
- Нет приватных донорских данных.
- Нет новых больших файлов.
- Старые аудио-плееры и карта не сломаны.

## Что Не Проверяем В Фазе 1

- полноценную автоматизацию платежей;
- закрытый доступ для подписчиков;
- каталог переводов;
- хронологию;
- видеоархив;
- поиск по текстам.

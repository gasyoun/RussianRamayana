# Manual Verification

## Локальный Сервер

Запустить:

```powershell
python -m http.server 8000
```

Открыть:

```text
http://localhost:8000/
http://localhost:8000/support.html
```

## Браузерная Проверка

Критерии:

- главная открывается;
- кнопка поддержки ведёт на `support.html`;
- `support.html` открывается;
- текст не налезает друг на друга на ширине 390px;
- текст не налезает друг на друга на ширине 1440px;
- аудио-плееры видны;
- карта открывается как раньше;
- в консоли браузера нет JavaScript-ошибок.

## Контентная Проверка

Проверить вручную:

- Гринцер представлен как начавший проект;
- Леонов представлен как продолжающий перевод;
- книга IV описана как блокированная и не оплачиваемая этим сбором;
- книга V: ориентир рукописи 2027;
- книга VI: полный черновой литературный перевод, ориентир 2029;
- связь с `Литературными памятниками`: `готовится для серии`;
- нет обещания закрытого доступа через GitHub Pages.

## UX Проверка

Критерии:

- посетитель за 10 секунд понимает, что собирается `1 000 000 руб.`;
- видна месячная цель `166 000 руб.`;
- видна кнопка `Поддержать перевод`;
- понятно, что есть разовый взнос и подписка;
- понятно, что зарубежным донорам будут отдельные способы.

## Fail Conditions

Фаза не принята, если:

- пропал аудиоблок;
- сломалась карта;
- появились реальные реквизиты или персональные данные;
- первый экран стал каталогом вместо сбора;
- закрытые черновики обещаны через GitHub Pages.

# Implementation Plan

Цель: дать Gemini Flash маленький, проверяемый путь внедрения, без попытки сразу перестроить весь сайт.

## Принцип

Первый релиз должен отвечать на один вопрос:

> Как посетитель понимает, зачем нужен сбор, сколько нужно собрать и как поддержать перевод?

Всё остальное, включая каталог переводов, хронологию, видеоархив и сравнительное чтение, откладывается до следующих фаз.

## Документы

- `phase-1-crowdfunding.md` — первая внедряемая фаза.
- `phase-1-data-contracts.md` — JSON-контракты первой фазы.
- `verification-and-tests.md` — обзор проверок.
- `verification-automated.md` — автоматические проверки.
- `verification-manual.md` — ручная браузерная и контентная проверка.

## Ограничения Для Gemini Flash

Можно менять:

- `index.html`;
- новые файлы в `data/`;
- новый `support.html`;
- новые файлы CSS/JS только если они нужны и подключены аккуратно;
- `CHANGELOG.md`, если фиксируется результат.

Нельзя менять:

- MP3;
- PDF;
- изображения;
- `ramayana-map-leaflet.html`;
- существующую audio preload логику без отдельной задачи;
- структуру папок с книгами;
- приватные донорские данные.

Нельзя добавлять:

- фреймворк;
- сборщик;
- авторизацию;
- поиск по текстам;
- реальные персональные данные доноров;
- большие бинарные файлы.

## Порядок Фаз

1. Фаза 1: краудфандинговый каркас.
2. Фаза 2: каталог переводов и пересказов.
3. Фаза 3: страница проекта Гринцер -> Леонов.
4. Фаза 4: хронология и начало Сундараканды.
5. Фаза 5: инвентаризация материалов и медиа.

## Фаза 1: Что Считается Готовым

- На главной есть явный блок сбора.
- Есть отдельная страница `support.html`.
- Есть `data/fundraising/summary.json`.
- Есть `data/project-status.json`.
- Сайт можно открыть локально и на GitHub Pages без сборки.
- Нет приватных данных.
- Не затронуты большие файлы и аудио.

## Минимальная Модель Данных

Данные на первом этапе нужны только для:

- суммы сбора;
- месячной цели;
- статуса книг IV-VI;
- способов поддержки.

Все остальные данные можно пока оставить в HTML.

## Риск

Главный риск — слишком широкий первый PR. Если задача расползается за пределы `index.html`, `support.html` и `data/`, её нужно остановить и разбить.

## Следующий Шаг

Передать Gemini Flash только:

- `phase-1-crowdfunding.md`;
- `phase-1-data-contracts.md`;
- `verification-and-tests.md`;
- `verification-automated.md`;
- `verification-manual.md`.

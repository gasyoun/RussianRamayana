# Phase 1: Crowdfunding Skeleton

## Цель

Добавить первый рабочий слой краудфандинга без полной перестройки сайта.

## Файлы

Создать:

- `data/fundraising/summary.json`;
- `data/project-status.json`;
- `data/payment-methods.json`;
- `support.html`.

Изменить:

- `index.html`;
- `changelog.md`.

Не трогать:

- MP3;
- PDF;
- изображения;
- карту;
- папки книг.

## Контент Главной

На `index.html` добавить видимый блок поддержки.

Обязательные элементы:

- цель: `1 000 000 руб.`;
- месячная цель: `166 000 руб.`;
- CTA: `Поддержать перевод`;
- ссылка на `support.html`;
- короткая формула: Гринцер начал, Леонов продолжает;
- статус: книга V готовится к рукописи в 2027, книга VI имеет полный черновой литературный перевод.

Тон: прямой краудфандинговый.

Не делать первый экран перегруженным каталогом, картой или аудио.

## `support.html`

Страница поддержки должна содержать:

- заголовок сбора;
- цель и прогресс;
- способы поддержки;
- подписка;
- разовый перевод;
- зарубежные способы;
- статус книг IV-VI;
- что получают подписчики;
- блок доверия;
- placeholder для отчетов.

Формулировка по книге IV должна быть прямой, но фактической:

> Книга IV задерживается из-за незавершенной вступительной статьи Серебряного; текущий сбор не может ускорить этот этап.

## JSON-Данные

Точные структуры JSON вынесены в `phase-1-data-contracts.md`.

Обязательное правило:

- не указывать реальные реквизиты, если они не предоставлены явно;
- не указывать персональные данные доноров;
- не пытаться автоматизировать импорт платежей в первой фазе.

## Критерии Готовности

- Главная ведет на `support.html`.
- `support.html` открывается без сборки.
- JSON валиден.
- Нет приватных данных.
- Нет новых больших файлов.
- Старые аудио-плееры работают как прежде.
- В `changelog.md` есть запись о фазе 1.

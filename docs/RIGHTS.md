# Реестр прав и источников материалов

Каждый материал проекта «Русская Рамаяна» имеет собственный правовой статус.
Этот реестр — единственный канонический источник; страницы сайта и метаданные
(Internet Archive и др.) должны ссылаться сюда или воспроизводить эти формулы.

Словарь статусов — [rightsstatements.org](https://rightsstatements.org/page/1.0/?language=ru):
`InC` = In Copyright (охраняется авторским правом), `CC BY` / `Apache-2.0` = свободные лицензии.

## Открытые вопросы

1. **Пункт 4 — блокер публичности IA-item.** Подтверждено (2026-06-12):
   разрешение Кривецкого покрывает *только запись*. Текст Потаповой —
   самостоятельный объект права (охрана до 2062 г. в РФ). Варианты:
   (а) запросить разрешение наследников Потаповой — предпочтительно;
   (б) загрузить на IA с ограниченным доступом (`access-restricted-item`)
   до урегулирования; (в) оставить текущую раздачу как есть и отложить IA.
   До решения — НЕ делать item публичным.
2. Хранить ли скан/копию письменного разрешения Кривецкого в `_private/`
   (в git не попадает) с указанием реквизитов здесь.

## Правила

- Новый материал не публикуется, пока у него нет строки в этом реестре.
- Для материалов, размещаемых на внешних платформах (Internet Archive,
  YouTube), формула rights в метаданных платформы копируется из этого реестра.
- Персональные данные доноров и приватные договорённости в реестр не
  заносятся — только публичные формулы.

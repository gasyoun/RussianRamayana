# Бюджет кампании 500 000 ₽ — структура распределения и запасной путь (черновик W0)

_Created: 06-09-2026 · Last updated: 06-09-2026_

**Статус: ЧЕРНОВИК.** Это исполнение п. 6 волны W0 программы H4093
([H4238](https://github.com/gasyoun/Uprava/blob/main/handoffs/H4238-OxAlpha_RussianRamayana_w0-rights-channel-matrix-500k-allocation_06.09.26.md)):
структура распределения фиксированной цели **500 000 ₽** и запасной путь по гейту V10.
Сбор НЕ активируется (запуск кампании — отдельное действие W3, после верифицированного
пакета). Числа-заглушки помечены ⚠️ и заполняются только подтверждёнными
счетами/расценками — фиксированная цель 500 000 ₽ единственное заданное число.

## 1. Результат кампании (deliverable — фиксируется здесь)

1. Печатное издание «Русской Рамаяны» (состав и тираж — по решению MG после расценок типографий).
2. Классный ридер — учебная производная с привязкой к каноническим passage-ID (права — по канальной матрице [RIGHTS.md](RIGHTS.md)).
3. Верифицированный кампаний-пакет (правовая матрица, бюджет этой страницы, платформенные метаданные).

## 2. Распределение цели 500 000 ₽

| Статья | Доля цели | Сумма | Основание / чем заполняется |
|---|---:|---:|---|
| Печать тиража книги | ~55 % | ⚠️ 275 000 ₽ | расценки типографий (тираж × себестоимость) — `@DO MG`: 2–3 котировкu |
| Классный ридер (макет + малый тираж) | ~15 % | ⚠️ 75 000 ₽ | вёрстка агентом + печать малым тиражом; объём от решения по формату |
| Правовые урегулирования | ~10 % | ⚠️ 50 000 ₽ | по реестру: наследники Потаповой (объект 4) — если выбран путь разрешения; Леонов — участник проекта (0 ₽); Гринцер — не размещается (0 ₽) |
| Кампания и платформы (IA/хостинг/промо-материалы) | ~10 % | ⚠️ 50 000 ₽ | фактические счета платформ |
| Резерв | ~10 % | ⚠️ 50 000 ₽ | непредвиденное; при неиспользовании снижает итог |

Итого = 500 000 ₽ ровно (доли округляются при заполнении фактуры; сверка — гейт V10 «totals reconcile»).

## 3. Запасной путь (fallback — результат выживает ниже цели)

Гейт V10 требует: «fallback remains deliverable below target» — обе ступени сохраняют
результаты (книга + ридер), уменьшая объём, а не результат:

1. **Ступень −25 %** (цель не достигнута на четверть): тираж книги сокращается
   (или print-on-demand вместо склада), ридер остаётся в плане.
2. **Ступень −50 %:** печать книги → print-on-demand; ридер → цифровой-first
   (PDF/учебная платформа вместо печати); правовая статья сохраняется полностью —
   это единственная статья, резать которую нельзя (она открывает внешние платформы).
3. Ниже половины цели кампания не запускает публичный сбор — по W3-правилу запуск
   отделён от пакета и требует отдельного решения.

## 4. Открытые входы (не выдумываются)

- Котировки типографий (тираж, бумага, объём) — `@DO MG`, 2–3 запроса.
- Решение по объекту 4 реестра (наследники Потаповой: путь «(а) разрешение» или «(б) IA-restricted») — влияет на статью «правовые урегулирования» и на канал «Внешн».
- Подтверждение платформенных издержек IA/хостинга — агент, после решения по объекту 4.

# Как читать листы сносок — краткая памятка переводчику (М. В. Леонов)

_Created: 12-07-2026 · Last updated: 12-07-2026_

Эта среда к каждой шлоке сама подбирает трудные слова и даёт по ним сноску:
как это слово передавали классики (Гринцер, Кальянов, Васильков и др.) с точной
ссылкой + краткую словарную глоссу. Ручной запрос в словарь и сверка глазами из
цикла уходят. Пилот — сарги 1–2 Сундараканды (кн. V), там есть с чем сверять:
Ваш собственный ручной аппарат.

## 1. Что Вы получаете

Один и тот же лист в трёх формах (выберите удобную — остальные оставим про запас):

| Форма | Файл | Как смотреть |
|---|---|---|
| **Word** | `sarga_N.docx` | Открыть в Word — сноски настоящие, внизу страницы. Ваш обычный процесс. |
| **Автономный лист** | `sarga_N.html` | Двойной клик — откроется в браузере, без интернета. |
| **Веб-режим (мок)** | `web_mock_sarga_N.html` | Как это будет в читалке samskrtam.ru: навести на номер — всплывает сноска. |

Все три приходят одним приватным `.zip`. **Листы не публикуются** — в них цитаты
из словарей и современных переводов под копирайтом; это Ваш рабочий инструмент.

## 2. Как устроена шлока на листе

```
1.4  dvijān vitrāsayan dhīmān urasā⁶ pādapān haran । ... pravṛddha⁸ iva kesarī
     Распугивая птиц, мудрый, грудью валя деревья ...

⁶ <слово> (देवнागари) — «передача» (Источник книга.шлока); «другая передача» (Источник). Словарь: <краткая глосса>
⁸ ...
```

- **Номер сноски стоит у своего слова** в строке (слева направо, как в книге).
- В сноске сначала — **как это слово переводили классики**, каждая передача со
  своим **locus** (откуда взята), потом — **словарная глосса** (помечена «Словарь»).
- Слово, у которого классики **расходятся** в передаче, показывается в первую
  очередь (ярус A) — это главная цель среды. Просто редкое слово с устоявшейся
  передачей идёт вторым ярусом (B).
- Слово, которое Вы **уже пояснили** в своём подстрочнике/заметке к этой шлоке,
  в сноску не дублируется.

## 3. Что от Вас нужно (пилот)

1. Выберите форму (Word / лист / веб) — какая удобнее в работе.
2. Отметьте **шум**: слова, по которым сноска лишняя (и так понятно).
3. Отметьте **пропуски**: трудные слова, которые среда НЕ засносковала, а стоило.

По Вашему отзыву настроим порог отбора и раскатаем на книги 6–7 (Юддха, Уттара).

## 4. Как пересобрать лист (для оператора)

Полный конвейер — в [README.md](https://github.com/gasyoun/RussianRamayana/blob/main/translator-env/README.md).
Кратко, на новую саргу N книги 5:

```
python src/difficulty.py --sargas N
python src/gen_sheets.py --sargas N        # -> sheets/sarga_N.{html,md} + web_mock
python src/render_docx.py --sargas N       # -> sheets/sarga_N.docx (нужен pandoc)
python src/build_samples_archive.py        # -> приватный .zip для переводчика
```

Методика и точность отбора — [VALIDATION_SARGA1.md](https://github.com/gasyoun/RussianRamayana/blob/main/translator-env/VALIDATION_SARGA1.md).
Родительский роадмап (волны 0–4) —
[docs/ROADMAP_LEONOV_TRANSLATOR_ENV_RAMAYANA_5_7_2026.md](https://github.com/gasyoun/RussianRamayana/blob/main/docs/ROADMAP_LEONOV_TRANSLATOR_ENV_RAMAYANA_5_7_2026.md).

# Русская Рамаяна (Russian Ramayana)

Цифровой корпус, архив переводов и краудфандинговая платформа для завершения первого полного поэтического академического перевода «Рамаяны» Вальмики на русский язык.

## О проекте

Сайт объединяет наследие академической школы П.А. Гринцера и современные труды М.В. Леонова по переводу великого санскритского эпоса. Проект осуществляется Обществом ревнителей санскрита под руководством М.Ю. Гасунса.

## Архитектура

Сайт построен как **data-driven static site**:
- **Frontend**: Чистый HTML5/CSS3 с использованием JavaScript (ES6+) для динамической загрузки данных.
- **Data Layer**: Все данные (сбор средств, каталог переводов, статусы книг, медиа) хранятся в формате JSON в директории `data/`.
- **Pages**:
  - `index.html` — главная страница и точка входа в сбор.
  - `support.html` — страница краудфандинга с прогресс-барами и уровнями поддержки.
  - `translations.html` — систематизированный каталог переводов и пересказов.
  - `project.html` — история проекта и команда.
  - `timeline.html` — хронология русской Рамаяны.
  - `media.html` — аудио- и видео-архив.
  - `compare/` — раздел сравнительного чтения эпизодов.

## Структура данных (`data/`)

- `fundraising/summary.json` — текущий прогресс сбора средств.
- `fundraising/levels.json` — уровни подписки и бонусы.
- `payment-methods.json` — реквизиты для пожертвований.
- `project-status.json` — состояние работы над Книгами IV, V, VI.
- `translations.json` — реестр академических переводов.
- `retellings.json` — реестр популярных пересказов и адаптаций.
- `people.json` — участники проекта.
- `timeline.json` — исторические вехи.
- `audio.json` — метаданные аудиокниги 1986 года.
- `videos.json` — видеоматериалы и цитаты.

Для обновления данных на сайте достаточно отредактировать соответствующий JSON-файл в папке `data/`. Сайт автоматически подтянет изменения при следующей загрузке страницы.

# Данные сбора средств — как обновлять

Эти файлы читаются страницами [support.html](../../support.html) и
[index.html](../../index.html) во время загрузки (`fetch`). Чтобы обновить цифры
на сайте — отредактируйте JSON, ничего пересобирать не нужно.

## summary.json

Два независимых сбора, показываются на странице отдельными блоками:

```jsonc
{
  "onetime": {            // Разовые пожертвования — шкала к общей цели
    "goal_rub": 1000000,  // цель, ₽ (Книги V–VI)
    "collected_rub": 0,   // собрано на сегодня, ₽   ← сюда реальную сумму
    "donor_count": 0      // число разовых жертвователей ← реальное число
  },
  "monthly": {            // Ежемесячная поддержка — регулярная «подушка»
    "goal_rub": 166000,   // цель, ₽/мес
    "pledged_rub": 0,     // текущая сумма ежемесячных подписок, ₽/мес ← реальное
    "supporter_count": 0  // число активных подписчиков ← реальное
  },
  "updated_at": "2026-05-14"   // дата последнего обновления (ГГГГ-ММ-ДД)
}
```

**Пустое состояние (нули).** Пока `collected_rub`/`pledged_rub` равны 0, страница
НЕ показывает «0 ₽ / 0 доноров» (это отпугивает), а выводит приглашение
«Сбор открыт — станьте первым». Как только впишете реальные ненулевые числа,
автоматически появятся суммы, проценты и шкала прогресса.

## levels.json

Уровни ежемесячной подписки (Ванара → Раджа). Поле `rewards` — список строк.

## payment-methods.json

Каналы оплаты. Пустой `"url": ""` рендерится как неактивная кнопка «Скоро».
Впишите реальную ссылку (или платёжную ссылку Сбербанка / Boosty / Patreon),
чтобы кнопка стала кликабельной.
